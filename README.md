# OpenTS for Apple

OpenTS is an Apache-2.0 native macOS and iOS client in early development for existing TeamSpeak 3 servers. The SwiftUI apps share a Rust session engine built on tsclientlib and Swift bindings generated by UniFFI.

The first milestone connects to a server address or server nickname, displays the live channel hierarchy and channel properties, and disconnects. Select a channel and choose **Join Channel**, or double-click it on macOS. The current channel is marked after the server confirms the move. Each connection currently uses a temporary identity. Voice input/output and administration are upcoming milestones.

## Build

On an Apple Silicon Mac with Xcode, XcodeGen and rustup installed:

```sh
rustup target add --toolchain stable aarch64-apple-darwin aarch64-apple-ios aarch64-apple-ios-sim
./scripts/build-apple-core.sh
open OpenTS.xcodeproj
```

Select the macOS or iOS scheme. The packaging script produces debug libraries for Apple Silicon Macs, arm64 iOS devices and arm64 simulators. To build and launch the Mac app directly, use `./script/build_and_run.sh`.
