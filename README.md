# OpenTS for Apple

OpenTS is a planned open-source native macOS and iOS client for existing TeamSpeak 3 servers. Both apps will share a Rust protocol core and Swift session code. The Android client is planned as a separate application repository.

The project is in the protocol evaluation stage. A macOS command-line probe using tsclientlib connected to the same virtual server by server nickname and by domain, verified its identity, and disconnected successfully. Native apps and voice interoperability are planned.
